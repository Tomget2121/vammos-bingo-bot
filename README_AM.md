# Vammos Bingo Bot — Version 1

ይህ የመጀመሪያ Demo ስሪት ነው።

## የሚሰራው
- Telegram Bot
- 5x5 Bingo card
- 20 ብር Demo ticket
- SQLite database
- የተጫዋች መመዝገብ
- 24/7 cloud deployment ለማድረግ ዝግጁ መዋቅር

## አስፈላጊ
BotFather token በኮዱ ውስጥ አታስገባ።
በserver environment variable እንደ `BOT_TOKEN` አስገባ።

## ቀጣይ ስሪት
- Telebirr/CBE Birr የክፍያ ማረጋገጫ (official API/merchant access ከተረጋገጠ በኋላ)
- Admin panel
- Game creation/start/stop
- Number calling
- Automatic BINGO validation
- Winner/prize calculation
- Audit logs
- Database backup
